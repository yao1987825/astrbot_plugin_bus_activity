# bus activity

AstrBot 插件：群里问一句「郴州 2 路有没有车」，直接回当前车辆位置。全国范围可用，不限于郴州。

```
有，2路 现在 1 辆在路上
往火车站：湘L12345 五岭广场 326m
往高铁西站还没车
```

## 覆盖

两家上游互补，插件按「掌上公交 → 车来了」顺序试，**有车的那家说了算**：

- 掌上公交：578 个城市/县区名（含县，如桂阳、永兴、资兴），实时车辆带车牌
- 车来了：320 个城市（含香港、台湾、新加坡），其中 20 个是掌上公交没有的（大连、攀枝花等）
- 合并后 598 个城市入口（278 个只有掌上公交有）；两家都查不到就明说查不到，不猜

## 用法

群里直接问，不用指令前缀：

- `郴州 2 路有没有车`
- `南宁 1 路到哪了`
- `香港 1 路还有几站`
- `资兴 1 路有车吗` —— 县级线路挂在所属地级市目录下，靠线路名前缀认（资兴1路、桂阳2路）
- `2 路有车吗` —— 不带城市时查配置里的默认城市

按站问也行：

- `从五岭广场到火车站坐什么车` → `从五岭广场到郴州火车站坐 2路 直达（10 站），下一辆约 4 分钟后到，坐过去 10 分钟`
- `我在五岭广场，2 路还有几站` → `2路到五岭广场：湘L01882D 约 6 分钟，还有 4 站（往火车站）`
- `五岭广场有几路车` → `五岭广场有：2路、3路、…`

问全城也行（线路不超过 60 条的城市，逐条扫实时）：

- `郴州还有哪条线路有车` → `郴州市这会儿有车在跑的有 3 条：` + 每条线路的车辆数和首末站

「从 X 到 Y」只做**直达**：拿两站的经停线路求交集，再按站序验方向，验不过的不算直达；
交集为空或方向都不对就明说，不编换乘方案（上游换乘接口 `CMD=112` 没验证过）。

线路号前面那串字如果既不是城市也不是已知线路前缀（比如「火星 1 路」），会明说认不出，
不会拿默认城市的线路凑一个答案。

## 触发方式

只有一个入口：**LLM 工具 `bus_query`**。用户问到公交、几路车、某站有哪几路、从某站到某站怎么坐、
某路车到哪了/还有几站/几分钟到，LLM 判断是公交的事就调它，插件返回真实查询结果，
**由 LLM 按用户这一句的问法组织回答**——插件不预设句子格式，也不抢着发消息。

工具返回的是数据原文，车牌、站名、分钟数都是上游原值，LLM 只负责转述，不许自己换算或补数据。
问「今天天气怎么样」这类不会调，正常运行 LLM 回复。

## 配置

`_conf_schema.json` 只有一项：`default_city`（默认 `郴州市`），消息里没写城市时用它。写简称也行，匹配时会去掉「市/区/县/特别行政区」后缀。

## 安装

把整个目录放进 AstrBot 的 `data/plugins/`，WebUI 插件页重载。依赖只有 `cryptography`（AstrBot 自带），无需 `requirements.txt`。

## 自检

```bash
python3 selftest.py          # 离线：解析、匹配、排版（不联网）
python3 selftest.py --live   # 再打两家真接口
```

## 已知边界

- 到站分钟用上游对目标站自己的预测（`CMD=104` 带 `STATIONORDER`，回 `routeOnStationRTimeInfoList`
  的 `busToStationTime` 分钟 / `busToStationCount` 站数）；上游每站最多只给最近 2 辆，
  其余车没有预测。站已过时它回 `busToStationCount=-1`、`busNumber` 为空，插件当「没预测」处理
- 「坐过去几分钟」上游不给，只能按 `dislist` 每段里程 ÷ `speedlist` 每段均速累（单位实测 m/min），
  不含停站和红绿灯，实际只会更久，所以说「约」
- 车来了没有到站预测也没有里程/均速表，只有掌上公交的线路才给分钟和站数，其余仍只报站数
- 按站查（「从 X 到 Y」「我在 X 站」）只走掌上公交的 `CMD=102`；车来了没有等价的站点搜索，
  所以只有车来了的城市（大连、攀枝花等）只能问线路号，不能问站
- 不做换乘规划、历史统计
- 「有没有车」＝该线路**两个方向**的在途车辆合计数；只有一个方向有车时不提另一个方向，两边都有车才照实写「往X还没车」
- 车来了部分车队没有车牌，车号显示的是平台内部编号
- 两家站名写法不一致（南宁同一组站，掌上叫「民生新民路口」、车来了叫「新民东葛路口」），所以**一次查询只用一家**，不合并站表
- 非官方接口，上游改协议只需修 `chelaile.py` 或 `query.py` 里对应的一次请求

接口细节见姊妹项目 [yulin-bus-activity](https://github.com/misakano7545/yulin-bus-activity) 的 `docs/掌上公交API.md` 与 `docs/车来了API.md`。
